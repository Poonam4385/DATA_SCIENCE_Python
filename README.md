# Data Science Projects with Python

This repository contains practical Data Science and Data Analysis projects developed using Python.

## Projects

### Airbnb Rental Price & Availability Analysis
Analyzed Airbnb listings to explore pricing patterns, availability, property types, and location-based trends.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

### Amazon Laptop Price Scraper
Built a Python web scraper to collect laptop names, prices, and specifications for comparison and analysis.

**Tools:** Python, BeautifulSoup, Requests, Pandas

## Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Web Scraping
- Data Interpretation
